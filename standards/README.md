# Standards 规范知识库

本目录保存经过来源核验的中文机关文稿规范知识，为 Drafting、Review 和确定性校验工具提供统一依据。

## 目录

```text
standards/
├── README.md
├── document-types/   # 文种定义、适用范围和必要要素
├── writing-rules/    # 起草、行文、内容和审核规则
├── formatting-rules/ # 版式、标点、数字等格式规则
└── sources/          # 来源索引及导入说明
```

## 当前状态

四份首批权威材料均已完成结构化提取、Agent逐条来源对照和项目维护者人工签核，目前处于测试前的候选状态。目录中的空白不代表缺少规范可以由模型自行补全；任何规则在测试完成前均不得作为正式能力启用。

当前已覆盖《党政机关公文处理工作条例》全部四十二条、GB/T 9704—2012、GB/T 15834—2011（含规范性附录A并登记资料性附录B）和 GB/T 15835—2011。覆盖状态和启用门禁见 [来源覆盖清单](sources/coverage.yaml)。

## 内容准入

正式规则必须：

- 来源于权威、现行、适用的正式材料；
- 标明来源文件和具体位置；
- 区分强制规则、条件规则、建议规则和项目门禁；
- 说明适用文种、组织关系和触发条件；
- 对无法程序判断的事项标记语义审核或人工复核；
- 不把经验文章、模板习惯或模型常识冒充为规范。

## 工作流程

1. 在 `sources/` 登记候选来源；
2. 由用户提供权威原文或可核验材料；
3. 核对文件身份、效力状态和许可边界；
4. 提取候选规则并精确标注来源；
5. 复核适用范围和规则等级；
6. 建立测试场景；
7. 将规则标记为启用。

详细设计见 [Standards 规范知识体系设计](../docs/standards-design.md)，外部材料要求见 [来源导入说明](sources/README.md)。

## 安全与版权

不得将涉密、敏感、内部未公开或未经授权的材料提交到公开仓库。公开可访问不等于允许完整复制和再分发；不能确认许可时，仓库只保存来源元数据、规则定位和原创结构化摘要。
