# 本地原始材料

本目录保存用户提供、用于规则提取和来源核验的原始材料。

目录内的 PDF 默认被 Git 忽略，原因是“可以公开读取”不等于“可以在开源仓库重新分发”。只有在确认许可范围后，才能单独决定是否提交原文。

处理要求：

- 不修改原始文件内容；
- 使用稳定文件名和来源编号；
- 在上级目录的 `source-index.yaml` 中记录哈希、页数和来源；
- 不放入涉密、敏感、内部未公开或未经授权的文件；
- 提取出的规则必须保留到具体条款或章节的定位；
- 删除或替换原始文件时同步更新来源索引。

克隆仓库后，本目录不会自动包含原始 PDF，需要使用者从来源索引中的权威入口自行取得。
